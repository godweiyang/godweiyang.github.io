我做了一个安卓工具百宝箱，专治生活里的各种“等一下”

关注公众号【算法码上来】，每日算法干货马上就来！

不知道大家有没有这种感觉：手机里的 App 越装越多，但真正到了某个小场景，还是会突然卡住。

比如朋友发来一个链接，你想转成二维码；刷到一个视频，你想保存下来；看到一个表情包灵感，你想从视频里截一段 GIF；家里 WiFi 信号忽强忽弱，你想知道到底哪个角落最拉胯；甚至电脑和手机之间传个文件，还要在聊天软件、网盘、数据线之间反复横跳。

这些事都不大。

但是它们有一个共同特点：每次遇到都很烦。

于是我就做了一个安卓小工具合集，名字也很朴素，叫 ToolBox 工具百宝箱。

它不是那种打开以后要注册、登录、会员、弹广告、看激励视频的“大而全”软件。我的想法很简单：生活里那些偶尔会用到、但用起来又不想折腾的小工具，干脆都塞进一个 App 里。

它能干什么？

目前里面放了不少我觉得实用的小工具。

视频下载

这个应该是大家最容易用上的功能。

平时刷到一些想收藏的视频，比如教程、搞笑片段、旅行攻略、做饭步骤，如果每个平台都各找一个下载工具，那手机很快就变成“下载器博物馆”。

ToolBox 里做了一个视频下载工具，目标就是：复制分享链接，粘进去，解析并下载。

它支持抖音、快手、小红书、B站这些常见平台。B站还支持登录后获取更高清的版本。

当然，这里也友情提醒一下：下载内容请遵守平台规则和版权要求，自己学习收藏可以，不要拿去乱传播。

二维码生成

二维码这个东西，平时不觉得重要，但一旦需要，就会发现很烦。

比如：

  • 给别人发 WiFi 或链接；
  • 做一个活动海报；
  • 临时把一段文字转成码；
  • 想做一个带 Logo 的二维码；
  • 想把二维码换个颜色，看起来别那么像打印店门口贴的。

ToolBox 里可以输入任意文本或链接，生成二维码，还能改颜色、改样式、加 Logo，最后保存到相册。

有时候一个小二维码，确实能让分享这件事优雅一点。

视频转 GIF

这个功能我个人挺喜欢。

很多时候，一个视频发出去太重，截图又表达不完整，GIF 就刚刚好。

ToolBox 里的视频转 GIF 可以选择本地视频，截取时间段，还可以裁剪画面区域。比如你只想截表情包里的脸，就不用把整个视频画面都塞进去。

做表情包、做教程动图、做演示小片段，都挺方便。

九宫格切图

朋友圈老艺术家应该会喜欢这个。

选一张图，自动裁成正方形，再切成 3×3 九张图。发朋友圈的时候按顺序发，就能拼成一个大图。

这东西不一定天天用，但用到的时候还挺有仪式感。

GIF 倒放

这是一个有点无厘头但很好玩的工具。

把 GIF 反过来播，有些画面会突然变得非常魔性。比如倒水变成吸水，摔倒变成原地复活，猫跳下去变成猫飞上来。

有时候工具不一定非要严肃，能让人笑一下也挺好。

分贝仪

这个功能适合两种场景。

第一种是认真场景：看看办公室、宿舍、家里装修到底有多吵。

第二种是不太认真但很真实的场景：证明一下到底是谁嗓门大。

它会调用手机麦克风，实时显示大概分贝，并画一条曲线。手机麦克风毕竟不是专业仪器，所以数值只能当参考，但用来做相对比较已经够用了。

WiFi 信号探测

这个功能适合被家里 WiFi 折磨过的人。

有些地方信号满格，有些地方明明离路由器不远却卡得像在登月。ToolBox 可以显示当前 WiFi 的 RSSI、频段、连接速率，还可以记录信号变化。

我还做了热力图探索，不过这块也很诚实地说一句：单靠手机传感器自动走一圈画出精准户型图，漂移会很明显。

后面更靠谱的方向，应该是“上传户型图 + 手动点位采样”。也就是用户在户型图上点一下当前位置，App 记录这一点的 WiFi 信号，最后生成真正有参考价值的家庭 WiFi 热力图。

这会比纯自动轨迹靠谱很多。

局域网文件互传

这个功能我觉得非常实用。

手机开一个临时 HTTP 服务，电脑浏览器扫码或输入地址，就能互传文件。

不用数据线，不用微信文件助手，不用登录网盘，不用担心文件被压缩，也不用在“发送到我的设备”里等半天。

只要手机和电脑在同一个 WiFi 下，就可以直接传。

这个功能特别适合：

  • 电脑给手机传 APK；
  • 手机给电脑传照片；
  • 临时传 PDF、压缩包、安装包；
  • 不想让聊天软件掺和文件传输的时候。

金属探测器

这个工具听起来有点像玩具，但还真能玩。

它利用手机磁力计检测周围磁场变化。靠近磁铁、铁制物体、某些金属结构时，数值会明显变化。

它不能替代专业金属探测器，也不能保证找到你丢的戒指，但拿来测试磁铁、找找桌子里哪块地方磁场异常，还是挺有意思的。

为什么要做成一个 App？

因为我越来越觉得，很多工具的最大问题不是功能不够，而是入口太分散。

一个二维码工具，一个 GIF 工具，一个文件互传工具，一个 WiFi 工具，一个图片工具……每个都单独装一个 App，最后手机桌面上全是“偶尔用一次”的软件。

ToolBox 的思路是反过来：

不追求每个功能都做到行业最强，只追求在你需要的时候，能立刻打开、立刻解决问题。

它像一个家里的小抽屉。

平时你不会天天打开它，但剪刀、胶带、螺丝刀、电池、针线这些小东西，真要用的时候都在里面。

ToolBox 就是手机里的那个小抽屉。

它适合谁？

我觉得比较适合这些人：

  • 喜欢折腾手机小工具的人；
  • 经常需要处理视频、图片、二维码的人；
  • 不想为一个小需求装一堆 App 的人；
  • 家里 WiFi、文件互传、手机传感器这些东西想随手测一测的人；
  • 单纯喜欢“工具百宝箱”这种感觉的人。

如果你是那种“手机里只装 8 个 App”的极简主义者，那它可能会让你破戒。

如果你是那种“这个功能以后肯定用得上”的收藏型人格，那它应该很对味。

后面还想加什么？

我脑子里还有一堆想法，比如：

  • OCR 扫描识别；
  • 图片压缩和格式转换；
  • 图片转 PDF；
  • EXIF 隐私清除；
  • 局域网剪贴板同步；
  • TOTP 动态验证码；
  • WiFi 热力图户型图模式；
  • 家庭物品位置记忆；
  • LED 字幕屏；
  • 更好玩的表情包制作器。

当然，工具类 App 最大的问题就是：想加的功能永远比时间多。

不过这也是它好玩的地方。

今天加一个小工具，明天修一个小体验，慢慢它就会变成一个越来越顺手的手机百宝箱。

如果你也经常被生活里这些“小麻烦”卡住，可以试试看。

说不定下一次你想找二维码、传文件、做 GIF、测 WiFi 的时候，就不用再临时满世界找 App 了。
